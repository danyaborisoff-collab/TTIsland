# Публикация на GitHub

## Готово в проекте
- Настроен GitHub Actions: Windows → проверки UI → компиляция C# без действий с железом → NSIS x64 → SHA-256 → черновик предварительного релиза.
- Нативные файлы вынесены из ASAR, чтобы их мог читать Windows PowerShell.
- Исключены зависимости, сборки, диагностические файлы и типовые секреты.
- Установщик не подписан сертификатом. Автоматической публикации стабильного релиза нет.

## Загрузка
Нужен ваш репозиторий и авторизованный доступ с правом записи. Пароли, токены и cookies нельзя присылать в чат. Рекомендуется сначала приватный репозиторий до проверки содержимого владельцем.

Из корня проекта при настроенном Git и входе в GitHub:

```sh
git init
git add .
git commit -m "Prepare TTIsland 0.16.3-rc.1 release"
git branch -M main
git remote add origin https://github.com/OWNER/REPOSITORY.git
git push -u origin main
git tag v0.16.3-rc.1
git push origin v0.16.3-rc.1
```

Если репозиторий уже содержит историю, не выполняйте force push: сначала работайте с его клоном и сохраните существующие файлы.

Вкладка Actions покажет сборку Windows. При успехе у тега появится draft prerelease с EXE, контрольными суммами, зафиксированным CI package-lock.json и отчётом компиляции. Можно также запустить workflow вручную без создания релиза: результат будет в Artifacts.

Первоначально в архиве нет package-lock.json: он не выдуман и локальная установка зависимостей здесь не выполнялась. Первая CI-сборка создаёт его и прикладывает к артефактам. После проверки добавьте этот lockfile в репозиторий и замените npm install на npm ci для воспроизводимых следующих сборок.

Перед публикацией проверьте установку, запуск, сохранение настроек, физические Wi-Fi/Bluetooth, звук и действия питания на Windows. Подтвердите отсутствие личных данных в диагностике и скриншотах. После этого владелец решает, публиковать ли предварительный релиз. Удалённой публикации из этого архива пока не было.
