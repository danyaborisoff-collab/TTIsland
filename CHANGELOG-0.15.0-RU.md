# TTIsland 0.15.0 — управление внутри острова

## Сделано
- Удалена кнопка «Настроить» с главной. Она не оставляет пустую строку.
- В описании Бири удалено упоминание фиолетового котика.
- Wi-Fi: выбор адаптера; включение и выключение радио; обновление списка сетей; уровень сигнала и тип защиты; подключение с паролем; подключение по сохранённому профилю; отключение; удаление профиля после подтверждения.
- Новые подключения к открытым сетям, WPA2-Personal и WPA3-Personal. Для Enterprise/WEP/старого WPA нужен уже настроенный профиль Windows. Скрытые сети не добавляются вручную в этой версии.
- Пароль передаётся системному контроллеру через stdin, не через командную строку, не хранится в localStorage и не возвращается в ответе. «Запомнить сеть» выключено по умолчанию; при включении профиль хранит Windows. Без него применяется временный WLAN-профиль.
- Bluetooth: реальное чтение и переключение радио, список известных/обнаруженных Windows устройств, сопряжение и удаление сопряжения с подтверждением. Запрос сопряжения может потребовать системного согласия. Список не является полноценным непрерывным сканером всех BLE-профилей; произвольное подключение Bluetooth-профилей не имитируется.
- Звук: системная громкость, mute динамиков и микрофона, уровень микрофона через Core Audio. Прежний выбор аудиовыхода сохранён.
- VPN: подключение и отключение сохранённых VPN Windows с сохранёнными учётными данными. Не управление сторонними клиентами WARP/v2Ray и не создание VPN-профиля.
- Дисплей: яркость на поддерживаемом WMI-дисплее. Без изменения разрешения, HDR, DDC/CI внешних мониторов или ночного света.
- Сеть: внутренний просмотр IPv4, шлюза и DNS активных интерфейсов.
- Тема Windows: раздельные переключатели светлой темы приложений и системы.
- Уведомления: пользовательский параметр всплывающих уведомлений Windows. Организационные политики могут его перекрывать; некоторые приложения требуют повторного входа. Это не управление каждым приложением отдельно.
- Камера/микрофон: просмотр доступных данных о согласии Windows, без небезопасного изменения разрешений и без фиктивных переключателей. Mute микрофона — в панели звука.
- Блокировка, сон, перезагрузка и выключение вызывают настоящие фиксированные команды Windows после отдельного подтверждения с отменой по умолчанию. Принудительное закрытие несохранённых приложений не используется.
- Новые панели не открывают ссылки ms-settings. Элементы прежней панели звука/дисплея также перенаправлены во внутренние панели.

## Как пользоваться
Полностью распакуй архив в новую папку. START-WINDOWS.cmd запускает приложение, BUILD-WINDOWS.cmd собирает установщик. Нужны Node.js 20+ и интернет при первой установке зависимостей. Это исходники, не готовый EXE.

Система → Сеть и Windows → Wi-Fi → включить переключатель → выбрать сеть → пароль → подключить.

В браузере железо недоступно: показана честная ошибка, а не демонстрационные сети. Новые Windows 11 могут запрещать список SSID без разрешения геолокации для классических приложений. Аппаратный выключатель радио, политики организации и заблокированный PowerShell программа не обходит.

## Проверка на твоём Windows-ПК
Запусти CHECK-WINDOWS.cmd. Скрипт сначала компилирует нативные C#-контроллеры, затем делает только запросы состояния Wi-Fi, Bluetooth, звука, VPN, оформления и согласий. Он ничего не переключает и не выключает компьютер. SYSTEM-CHECK.json не содержит паролей или названий SSID; его можно прислать для диагностики.

## Что проверено здесь
Chromium/Playwright: панели Wi-Fi и ввод пароля, подключение/отключение/удаление профиля, ошибки без фиктивного переключения, Bluetooth, VPN, звук, тема, яркость, маршрут выключения, отсутствие открытия настроек Windows, отсутствие кнопки на главной, описание Бири и узкая светлая тема. Системные ответы имитировались.
Проверены ограничения входных данных, фиксированный запуск без shell, передача пароля только через stdin, исключение параллельных операций, обработка ответов и отмена действий питания.

ВАЖНО: эта среда — Linux, не Windows. Реальная компиляция C# в Windows, связь с WLAN/Bluetooth-драйверами, сопряжение, выключение/сон и сборка EXE здесь НЕ выполнялись. Нельзя считать их подтверждёнными испытанием на реальном ПК. Для этого добавлена CHECK-WINDOWS.cmd. Это не заявление о полной реализации всех настроек Windows.
