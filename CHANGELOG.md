# TTIsland 0.10.1 — исправление аудио и Bluetooth

- Исправлен неверный IID IMMDeviceCollection по Microsoft Windows SDK: CC5392387B5E вместо ошибочного C0A0B2E9745F в последней части идентификатора. Остальные интерфейсы не менялись.

# TTIsland 0.10 — пять новых функций

## Где найти
1. **OCR:** Главная → Снимок экрана. В редакторе нажмите «Область OCR», выделите прямоугольник, выберите язык и «Распознать текст». Без выделения читается весь снимок. Результат можно исправить и скопировать. В профиле «Лёд» есть отдельная быстрая кнопка «Текст со скрина».
2. **Аудиовыход:** вкладка «Система» → «Куда выводить звук». Выберите активное устройство. Меняется системный выход по умолчанию для ролей Console/Multimedia. Устройство связи и микрофон не меняются; приложения с явно выбранным выходом могут остаться на своём устройстве.
3. **Bluetooth:** вкладка «Система» → «Заряд Bluetooth». Показываются последние доступные сведения драйвера. «Нет данных» не означает 0%. Обновление ручное, ответы кешируются 20 секунд. Наличие в списке не доказывает текущее соединение.
4. **Профили:** Настройки → Профили оформления. Три готовых профиля; до 20 собственных. Сохраняются цвет каждого эффекта, анимации, вид контура и шесть быстрых кнопок. Захват, микрофон, история буфера и системные устройства профилем не включаются.
5. **Звуковой контур:** Настройки → Реакция на звук → Включить анализ. Требуется отдельное подтверждение. Анализируется общий системный звук Windows, в том числе других приложений. Для loopback Electron захватывает экран с низкой частотой кадров: кадры не сохраняются, не отображаются и не передаются. Микрофон не запрашивается. Зелёная кнопка в шапке, видимая и в свёрнутом острове, останавливает анализ. После перезапуска приложения анализ выключен. Одновременно с записью экрана не запускается; после переключения выхода его нужно включить заново.

## Windows и ограничения
- Windows 10/11, встроенный Windows PowerShell 5.1, обычная учётная запись. Администратор и внешние пакеты не требуются. Системная политика организации может запретить запуск PowerShell; тогда функция покажет ошибку.
- OCR использует установленный языковой компонент Windows (русский/английский/язык профиля), без облака. Временный PNG создаётся в пользовательской временной папке и удаляется после распознавания. Изображение уменьшается до 2400px по большей стороне. При отсутствии языка его нужно добавить в настройках Windows.
- Переключение аудиовыхода использует Windows Core Audio и недокументированный интерфейс PolicyConfig. На некоторых версиях Windows может не работать; остаётся кнопка системных настроек звука.
- Заряд доступен не для каждого Bluetooth-устройства; данные могут быть устаревшими. Bluetooth-совместимость зависит от драйвера.
- Реальная Windows-машина здесь недоступна: COM/WinRT, драйверы и реальный loopback пока не проверены на устройстве. Проверены интерфейс, сохранение, обрезка OCR, отмена/границы захвата и анализ настоящего синтетического аудиосигнала в Chromium. Это экспериментальная системная сборка, не гарантия поддержки любого оборудования.

## Обновление
Полностью выйдите через трей. Замените все файлы, включая **extras.js**, **desktop-tools.cjs** и папку **native**. Запустите START-WINDOWS.cmd. Для установленного EXE пересоберите BUILD-WINDOWS.cmd. Настройки и вход в сервисы хранятся в прежнем профиле island-lab. Новых npm-зависимостей нет.

# TTIsland 0.9 — громкость и прогресс

Добавлены полоса прогресса, время трека и громкость между обложкой/названием и кнопками плеера. Клик или перетаскивание полосы выполняет перемотку, если её поддерживает источник. Доступны громкость 0–100% и кнопка выключения/возврата звука. Меняется громкость встроенного музыкального плеера, не громкость всей Windows.

Для неподдерживаемого источника соответствующий ползунок неактивен. Прогресс не выдумывается: берётся из плеера, с короткой интерполяцией между обновлениями. Перемотка защищена от смены трека во время перетаскивания. Действия не открывают веб-панель.

Размеры острова, настройки цветов и три эффекта контура сохранены. Полностью выйдите через трей, замените ВСЕ файлы в прежней папке, запустите START-WINDOWS.cmd. Если нужен установленный EXE — пересоберите BUILD-WINDOWS.cmd. Старый профиль island-lab и Windows appId намеренно не меняются: вход в аккаунты и настройки сохраняются.

Проверено на реальном HTMLAudioElement в Chromium и на тестовых MediaSession/externalAPI. Реальный аккаунт Яндекса и Windows-сборка здесь не проверялись. Для музыкальных команд требуется вход в Яндекс через «Поиск / настройки».

## Установка обновления
1. В старом Island откройте Настройки → «Выйти из приложения». Просто свернуть или закрыть веб-вкладку недостаточно: оставшийся старый процесс не даст запустить новую версию.
2. Распакуйте архив в новую папку.
3. Откройте `island-app/START-WINDOWS.cmd`. Нужны Windows 10/11 и Node.js LTS, интернет для первой установки npm-зависимостей.
4. В настройках новой версии видна надпись `TTIsland 0.8`. Это позволяет убедиться, что запущена не старая версия.

Обычный ручной запуск: `npm install`, затем `npm start` в папке с package.json. В архиве исходники, НЕ готовый установщик. Сборка установщика на Windows: `npm run dist:win` (неподписанный, SmartScreen может предупреждать).

## Музыка: что переработано
Для Яндекс Музыки теперь есть ранний изолированный preload, выполняемый до скриптов сайта. Он сохраняет зарегистрированные самим сайтом обработчики стандартной Media Session: `play`, `pause`, `nexttrack`, `previoustrack`. Кнопки острова в первую очередь вызывают именно эти обработчики, а не произвольные элементы страницы. Резервные варианты: внешний интерфейс плеера, если он предоставлен страницей, затем строго определённые элементы основного транспортного плеера, затем HTML-медиаэлемент для паузы. Кнопки карусели/плейлиста не используются вместо Next.

Новый музыкальный preload не даёт сайту доступ к IPC, файловой системе, Node.js, ключам, паролям и системным функциям. Он лишь оборачивает стандартный метод Media Session в контексте страницы. Требуется перезапуск приложения, чтобы ранний обработчик установился до загрузки сайта.

«Моя волна» и «Любимые» остаются фоновыми: сайт не раскрывается ни при успехе, ни при ошибке команды. Веб-панель открывается по явному нажатию «Поиск / настройки» или музыкальной вкладки. Первый вход в аккаунт обязателен. Подписка и доступ зависят от Яндекса. Фоновый сайт всё равно загружается — это не офлайн-плеер и не официальный API-интегратор.

ВАЖНО: подключение нового механизма к реальному Яндекс-аккаунту на Windows здесь не проверено. Если сам сайт не зарегистрировал Media Session и не предоставляет подходящие резервные элементы, команда вернёт ошибку. Для точечной отладки в Настройках есть «Диагностика музыки»: по вашему нажатию сохраняется JSON с доступными медиакомандами и подписями кнопок. Токены, cookies, пароли, тексты чата и HTML страницы не сохраняются; название текущего трека может присутствовать. Такой файл можно прислать для исправления совместимости.

## Скринкаст
1. Откройте «Скринкаст» или «Запись экрана» на главной.
2. Выберите экран или окно по миниатюре.
3. По желанию включите системный звук (поддержка loopback — Windows). Микрофон НЕ записывается.
4. Нажмите «Начать запись» и выберите файл сохранения.
5. Запись можно поставить на паузу и продолжить. Красная кнопка в шапке с таймером останавливает и сохраняет запись из любой вкладки.

Формат: WebM, VP9/VP8 в зависимости от поддержки, до 30 кадров/с. MP4-конвертация не включена. Файл пишется на диск порциями, вся запись не держится в памяти. При ошибке диска запись останавливается. При выходе во время записи приложение предложит остановить её, сохранить и выйти. При аварийном завершении последняя часть файла может быть повреждена.

Источник выбирается только пользователем. Захват доступен только привилегированному локальному окну после явного старта и выбора файла, не сторонним сайтам. Разрешение на захват используется один раз и имеет срок действия. Записи не загружаются в сеть. Будьте внимательны: выбранный экран может содержать личные данные, уведомления и сам остров. Системный звук может включать звук других приложений; защищённый контент/аудио может не захватываться.

HTML-файл, открытый отдельно в браузере, использует штатный диалог демонстрации экрана и скачивание WebM; для него нужен поддерживаемый браузер и безопасный контекст. В браузерном режиме ограничение памяти записи — 256 МБ. Настольная версия пишет порциями без этого ограничения.

## Анимации
- Пульсирует сам контур острова: форма, внутренний свет и внешнее свечение, пока источник сообщает воспроизведение.
- Исправлена область клика: вся шапка больше не является областью перетаскивания. Перетаскивание — только за отдельный значок из точек. Нажатие на шапку/плюс раскрывает остров.
- Открытие и закрытие меняют реальные размеры с анимацией; вкладки появляются со сдвигом, прозрачностью и лёгким размытием; название трека меняется с короткой анимацией.
- Настройки → «Анимации острова»: «Полные» (по умолчанию по запросу пользователя), «Как в системе» или «Выключены».
- Контур — декоративная пульсация по состоянию воспроизведения, НЕ настоящий анализ громкости и НЕ физическая вибрация устройства.

## DeepSeek и остальные возможности
Официальный веб-чат DeepSeek внутри острова, без API-ключа; потребуется вход в аккаунт. История и лимиты определяются самим сервисом. Также остались заметки, таймер, временная полка файлов, снимки экрана с рисованием и история текстового буфера по явному включению.

Alt+Space — переключить остров, если сочетание свободно; Esc — свернуть. Кнопки музыки доступны и в свёрнутом состоянии. Остановка скринкаста доступна красной кнопкой. Сессии сервисов сохраняются локально в профилях Electron.

История буфера по умолчанию выключена, при включении хранится локально без шифрования и может содержать секреты. Во время открытой веб-панели её опрос приостанавливается, но это не полная защита. Не копируйте секреты при включённой истории.

## Проверки и ограничения
Проверены: ранний перехват реальных браузерных Media Session handlers на контрольной странице без audio-элемента, правильные pause/play/next/previous; изменение контура во времени; активные анимации открытия/закрытия и вкладок; выбор источника; настоящий MediaRecorder, кодировавший тестовый canvas-stream в WebM; пауза/продолжение/остановка и запись байтов; мобильная ширина и переключатель анимаций. Созданный тестовый WebM прочитан ffprobe как VP9 640×360. Это не имитация видеокодирования, но и не проверка захвата рабочего стола.

Реальный Яндекс-аккаунт, Windows/Electron, системный звук Windows и системные разрешения на захват здесь не проверены. Не обещаем, что конкретный аккаунт сайта не изменил обработчики или не заблокирует встраивание. Подробности — TEST-RESULTS.json.

Нет OCR, погоды, нативной MP4-конвертации, микрофонной записи, офлайн-DeepSeek или обхода подписок/DRM.


## TTIsland 0.11 — платформы, Bluetooth и голос

Полностью закрой приложение через трей и замени все файлы, включая новые JS/CSS и папку native. Профиль appData/island-lab и старые разделы persist:island-yandex / persist:island-deepseek сохранены. Установленный EXE пересобрать через BUILD-WINDOWS.cmd.

### Музыка и ИИ
На главной нажми стрелку рядом с названием Яндекс Музыки: Яндекс / SoundCloud / VK / Spotify. Выбор не открывает сайт поверх главной. «Войти / открыть» — официальный сайт внутри панели. Для каждого сервиса отдельный постоянный раздел cookies. Пароли вводятся только на странице самого сервиса; приложение их не извлекает. При переключении играющий старый источник сначала пытается остановиться; при неподтверждённой паузе переключение отменяется.

Обычные кнопки используют MediaSession/HTMLMediaElement либо ограниченный набор известных элементов плеера. Это не API-обход, не загрузчик музыки и не гарантия работы DRM или доступа в РФ. В Spotify могут отсутствовать необходимые DRM-компоненты Electron; у Google вход из встроенного браузера может быть запрещён. «В браузер» открывает официальный сайт, но внешний браузер не управляется этим адаптером и его вход не импортируется назад. Яндекс-специфические «Волна» и «Любимые» сохранены только для Яндекса.

ИИ: DeepSeek, Claude, Gemini, ЯндексGPT/Алиса — веб-чаты без API-ключей. Собственная авторизация, подписки, географическая доступность и ограничения сайтов сохраняются; чат не подменяет платный API. Удалённые страницы не имеют IPC, файлового доступа, камеры или микрофона.

### Bluetooth
WinRT AssociationEndpoint → ContainerId → связанные Device-узлы → батарея Windows. Читаются сопряжённые Classic Bluetooth устройства, не только аудио. Не обещаем BLE-only устройства, заряд кейса или отдельные левый/правый наушник. При ошибке WinRT включается резервный PnP-поиск; он не подтверждает подключение. Неизвестные уровни не рисуются как 0%. После подключения подожди несколько секунд и обнови список.

### Голосовые заметки
Заметки → «Записать», разреши микрофон → «Стоп» → «Распознать» → проверь текст → «В заметки». До 2 минут; PCM WAV 16 кГц/16 бит/моно. Есть прослушивание, сохранение WAV и импорт такого же WAV. MP3/M4A пока не импортируются. Микрофон закрывается при переходе в другой раздел, закрытии приложения или по кнопке в шапке. Текст остаётся локальным; аудио остаётся только в памяти до очистки/выхода, если не сохранено вручную. Временный WAV для движка удаляется после операции.

Офлайн-распознавание использует установленный Windows System.Speech. Нажми «Проверить движок»: наличие русского интерфейса Windows НЕ гарантирует наличие русского DictationGrammar/System.Speech. Если движка нет, приложение сообщает это, а не выдаёт выдуманный результат. Win+H — отдельная штатная диктовка: кликни в поле текста и нажми Win+H; её сетевые настройки определяет Windows. Универсальная модель Whisper/Vosk не включена.

### Оформление и лицензия
Настройки → Размер и положение: ширина развёрнутого и свёрнутого островка, высота виджета. Перемещение за точки слева от глаз; положение сохраняется. Веб-панель имеет отдельный размер. Глазки, обложки и прежние контуры сохранены. Наш исходный код MIT; чужой GPL/CC BY-SA код не скопирован. См. THIRD-PARTY-NOTICES.md перед распространением сборки. Список ещё не реализованных идей — ROADMAP.md.

### Проверка
Проверяется JavaScript, маршрутизация, меню, ошибки, PCM WAV, микрофон и макет в Chromium с тестовыми мостами. Реальный Windows COM/WinRT, Bluetooth-драйверы, System.Speech, аккаунты и DRM в этой среде НЕ проверены.


## TTIsland 0.12 — замкнутый контур и жизнь в трее

Исправлена реальная причина нижних штрихов: в 0.11 нижняя граница островка совпадала с краем прозрачного окна. Контур уходил за пределы окна. В 0.12 резервируются прозрачные поля сверху, снизу и по бокам; высота внутреннего содержимого учитывает эти поля. Свёрнутое окно имеет высоту 100 px, но сам компактный островок не увеличен.

Весь периметр пересчитывается в одной геометрии с внешними нормалями, замыкается без шва, учитывает радиус и DPI. Нет CSS-рамки поверх Canvas. Сохранены Волны, Пульсация и Шипы; добавлены Орбита и Северное сияние. У каждого режима свой цвет, включая сохранение в профили. Кнопка предпросмотра работает 8 секунд без музыки; при отключённых анимациях контур не запускается.

Перемещение: зажми левой кнопкой область точек слева от глаз, перетащи и отпусти. Используется положение курсора Windows, а не ненадёжное смещение внутри движущейся страницы. Положение сохраняется после отпускания, окно ограничено рабочей областью экрана. Настройки позволяют сбросить положение и размеры.

×, Alt+F4 и минимизация скрывают окно в трей; приложение и музыка продолжают работать. Alt+Space из скрытого состояния всегда ПОКАЗЫВАЕТ развёрнутый островок; когда окно уже видно, сочетание переключает компактный/развёрнутый режим. Клик по трею и «Показать остров» тоже восстанавливают окно. «Выйти полностью» в трее или «Выйти из приложения» в настройках завершают процесс. При явном выходе во время скринкаста остаётся прежнее подтверждение сохранения. Простое скрытие НЕ завершает скринкаст. Микрофон и анализ системного звука при скрытии останавливаются.

Если Alt+Space занята, приложение сообщает об этом; трей остаётся запасным способом восстановления. Если недоступны и трей, и сочетание, окно не скрывается. START-WINDOWS.cmd запускает GUI Electron отдельно от терминала после установки зависимостей.

Проверка: Chromium/DPI/пиксели контуров и изолированные тесты событий окна/трея. Реальный Windows shell, драйверы и аппаратные интеграции здесь не запускались.
