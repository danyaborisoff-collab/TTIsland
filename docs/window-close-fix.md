# Исправление кнопки скрытия окна

Кнопка справа в шапке больше не использует текстовый символ ×. Вместо него — симметричная SVG-иконка 12×12, выровненная по центру.

Убраны системные отступы и зависимость от базовой линии шрифта: раньше строка 31,5 px вместе с отступами попадала в кнопку высотой 30 px. Новая кнопка фиксирована на 28×28 px, не раздувается при наведении и нажатии; фон учитывает палитру.

Сохранены скрытие в трей, подсказка, доступное название, управление с клавиатуры и скрытие кнопки в круглой мини-форме. Таймер трека, песочная и бордовая темы остаются в проекте.

Проверка: npm run test:window-close. Нативный запуск в Windows не выполнялся.
