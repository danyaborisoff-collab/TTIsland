# Таймер трека и новые палитры

## Мини-плеер

Под названием трека теперь есть отдельная строка `0:01 / 2:12`. Название поднято примерно на 4 CSS-пикселя. Строка работает и в раскрытой шапке, и в мини-виджете.

Используются реальные position / duration и существующий meterAnchor: новый аудиоисточник и второй таймер воспроизведения не добавлены. Пауза останавливает счётчик, перемотка и смена трека используют обновлённое состояние плеера. Значение ограничено длительностью; при неизвестной длительности показывается `--:--`. Без подключённого трека строка скрыта. Помодоро, запись экрана, голосовая запись и круглая мини-форма сохраняют свои существующие приоритеты.

## Оформление

В Настройки → Оформление → Цвет острова:
- **Песок**: более насыщенный кремово-песочный фон, тёплые карточки и карамельный акцент, как в песочной видеодемонстрации. Это больше не почти белая палитра.
- **Бордовая**: винный фон, глубокие бордовые карточки, пыльно-розовый вторичный текст и светлый медный акцент.

Обе палитры сохраняются в обычных настройках и пользовательских профилях. Форма, виджеты, эффект контура и его индивидуальный цвет от смены палитры не меняются. Нативное окно остаётся прозрачным вне острова; тёплый/винный фон страницы применяется только к браузерному предпросмотру.

## Проверка

`npm run test:compact-track` — проверки часов, паузы, перемотки, смены трека, скрытия при Помодоро/записи, мини-форм, сохранения тем, профилей, цветов и адаптивной шапки.

`node tests/themes.cjs` и `npm run test:release` — существующие регрессионные проверки. Нативные Windows-интеграции и сборку установщика необходимо дополнительно проверить в Windows: браузерные тесты не заменяют такой запуск.
