# TTIsland 0.14.0 — Living / Биря

## Что изменилось
- Добавлен рыжий полосатый котик **Биря** — в память о Бире. Фиолетовый котик сохранён.
- Персонажи следят за курсором, реагируют на ласку, игру, музыку, запись и сообщения приложения; засыпают после бездействия. Правый клик — меню взаимодействий, Enter/Space — ласка или открытие свёрнутого острова.
- Реакции, танцы, сон, время до сна и размер персонажа настраиваются отдельно.
- Новый режим **Жидкий остров**: единый плавный контур с локальным притяжением к курсору. Можно оставить движение без музыки или отключить для экономии ресурсов.
- Раздельная непрозрачность фона раскрытого и свёрнутого острова; текст остаётся непрозрачным. Поддерживаются отключение анимаций и системное уменьшение движения.
- Настройки разделены: Оформление / Персонажи / Виджеты / Окно / Windows / Приватность. Старые элементы перемещены вместе с обработчиками, а не заменены заглушками.
- Система разделена: Обзор / Звук и устройства / Сеть и Windows / Питание.
- Кнопки Windows открывают Wi-Fi, Bluetooth, VPN, звук, дисплей, сеть, тему, уведомления и разрешения микрофона/камеры. Это переходы в настройки ОС, не прямые переключатели радиомодулей.
- Блокировка, сон, перезагрузка и выключение — через фиксированные разрешённые команды и отдельное подтверждение с отменой по умолчанию.
- Автозапуск установленного приложения и исключение окна из совместимых средств захвата Windows. Защита захвата не гарантирует невидимость во всех программах.
- Добавлены контекстные кнопки «Настроить»; быстрые виджеты звука и батареи открывают нужный подраздел устройств.
- Настраиваются задержки открытия и закрытия при наведении. Новый эффект сохраняется в профилях оформления.

## Запуск
1. Полностью распакуй архив в отдельную папку. Не удаляй прежнюю рабочую версию до проверки.
2. Для настольного приложения на Windows используй START-WINDOWS.cmd (нужны Node.js 20+ и интернет при первой установке зависимостей).
3. Для установщика используй BUILD-WINDOWS.cmd. Автозапуск включается только в установленной сборке.
4. index.html можно открыть для предварительного просмотра интерфейса. Системные действия в обычном браузере недоступны.
5. Биря: Настройки → Персонажи → Биря. Жидкий контур: Настройки → Оформление → «Включить жидкий остров».

## Проверки и ограничения
Проверены браузерный интерфейс Chromium/Playwright, сохранение настроек, старые функции, музыкальные контроллеры на локальных тестовых страницах, анимации, узкий экран 390 px и светлая тема. Мост новых системных действий проверен с имитацией Windows: разрешённые действия, защита отправителя, подтверждения и отмена.
В этой среде не запускались Windows/Electron, не собирался EXE-установщик и не выполнялись реальные выключение, сон, автозапуск или защита захвата. Их нужно проверить на целевом ПК. Это исходники, не готовый установщик.
