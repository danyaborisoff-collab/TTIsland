# TTIsland 0.16.3-rc.1

Предварительная версия для Windows 10/11 x64.

## Главное
- «Жидкий остров» — один общий переключатель непосредственно под выбором стиля контура. Он работает со всеми темами, сохраняет силу и состояние при смене оформления.
- На главном экране нет кнопок и шестерёнок настроек. Настройки доступны с других вкладок и по Ctrl+,.
- Рыжий кот Биря, живые реакции персонажей, пять палитр и внутренние панели устройств.
- Исправлена упаковка нативных контроллеров: PowerShell получает реальные файлы из app.asar.unpacked, а не недоступный для него виртуальный путь внутри app.asar.

## Установка
После успешной сборки скачайте TTIsland-0.16.3-rc.1-Setup-x64.exe и при необходимости сверьте SHA-256 с SHA256SUMS.txt. Для установки EXE Node.js не требуется.

Установщик не подписан сертификатом издателя. Windows может показать предупреждение SmartScreen. Не отключайте антивирус и не обходите запреты управляемого компьютера; если не уверены в происхождении файла, не запускайте его.

## Статус проверки
Здесь пройдены Chromium-проверки интерфейса и тесты с имитацией Windows API. GitHub Actions дополнительно должен скомпилировать C# на Windows, собрать установщик и проверить наличие нативных файлов. До первого успешного запуска Actions установщик не считается собранным.

Физические Wi-Fi/Bluetooth-адаптеры, сопряжение, реальное выключение/сон и запросы согласий требуют проверки на целевом Windows-ПК. Успешный CI не заменяет эту проверку. Поэтому релиз создаётся как draft + prerelease, а не объявляется стабильным автоматически.

## Ограничения
Сканирование Wi-Fi в Windows 11 может требовать разрешения геолокации. Камера/микрофон не получают согласие пользователя обходным путём. VPN — сохранённые профили Windows, Bluetooth — доступные Windows устройства и сопряжение, яркость — поддерживаемые дисплеи. Разрешение, HDR, ночной свет и управление сторонними VPN не реализованы.
