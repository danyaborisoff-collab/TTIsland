# TTIsland 0.17.0-rc.3

Предварительный выпуск для Windows 10/11 x64.

## Что изменилось
- Жидкие эффекты, капли и прилипание острова к верхнему краю с расширенной кромкой.
- Ползунок «Хаос эффекта» 0–100 %, нерегулярные всплески контура и короткий предпросмотр без музыки.
- Удалены хаос и случайные трюки персонажей. Минималистичные белые глазки; скорость анимации 25–400 %.
- Обновлены разрешения музыкальных сервисов и сообщения об отсутствии DRM.

## Установка
Скачайте единственный прикреплённый файл `TTIsland-0.17.0-rc.3-Setup-x64.exe`. Полностью выйдите из старой версии через трей и запустите установщик. Node.js не требуется. SHA-256 указан ниже.

Установщик не подписан сертификатом издателя; Windows может показать SmartScreen. Проверяйте источник и контрольную сумму, не отключайте защиту Windows.

## Проверки и ограничения
Публикация выполняется только после release-тестов, проверок rc.3, компиляции нативных контроллеров на Windows и успешной упаковки NSIS. Автоматические проверки не заменяют запуск на реальном Windows-ПК: устройства, аккаунты, системные действия и качество анимации требуют отдельной проверки.

Это стандартный Electron 42, не castlabs/Widevine. Защищённое воспроизведение Apple Music в этом EXE не гарантируется. DRM-скрипты исходников не превращают стандартную сборку в DRM-сборку автоматически.

Версия намеренно отмечена prerelease. Стандартные ZIP/TAR исходников добавляются самим GitHub; вручную загружается только EXE.
