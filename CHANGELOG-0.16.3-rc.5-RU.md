# TTIsland 0.16.3-rc.5 — плавная главная

- При сворачивании главная сохраняет исходный размер и не пересобирает сетку по узкому экрану, пока она видна. Её содержимое плавно исчезает вместе с уменьшением панели.
- При возвращении из большого сервиса главная проявляется только после расчёта целевого размера. Высота сетки не пересчитывается на каждом кадре, а нижняя панель движется вместе с внешним контуром.
- Убрано ограничение ширины полотна контура во время перехода: оно не сжимается раньше самой панели. Сохранены обработка быстрых разворотов и режим с отключённой анимацией.
- Добавлен `tests/motion-home-smooth.cjs`: проверка двух проблемных сценариев, перехода из большого вида в минимальный и быстрого разворота. Проверка `service-bottom-frames.cjs` учитывает фиксированный размер содержимого главной и проверяет анимацию внешней поверхности.

## Запуск

Полностью выйдите из старой версии через трей → «Выйти полностью», распакуйте весь архив в новую папку и запустите `START-WINDOWS.cmd`. В настройках должна быть версия `0.16.3-rc.5`. Для установленной версии пересоберите установщик через `BUILD-WINDOWS.cmd` и установите новый EXE из `dist`.

Это исходники, не готовый EXE. При первой установке зависимостей нужны Windows, Node.js LTS 20+ и интернет.

## Проверка и ограничения

Проверено в Chromium на Linux с имитацией нативного окна и Windows API. Реальные Windows, Electron, видеодрайвер и установщик не запускались. Реальную плавность и возможные рывки на конкретном ПК нужно проверить на Windows; результат симуляции не гарантирует определённой частоты кадров.
