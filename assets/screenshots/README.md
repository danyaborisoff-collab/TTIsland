# Скриншоты TTIsland

Эта папка предназначена для скриншотов приложения.

## Необходимые скриншоты

Добавьте следующие изображения:

1. **main-screen.png** — Главный экран с развернутым островом
2. **compact-mode.png** — Свернутый компактный режим с управлением музыкой
3. **effects.png** — Демонстрация анимированных эффектов контура
4. **screencast.png** — Интерфейс записи экрана
5. **ai-chat.png** — Один из ИИ-чатов в действии

## Рекомендации по созданию скриншотов

- Разрешение: не менее 1280x720
- Формат: PNG (с прозрачностью где возможно)
- Убедитесь, что на скриншотах нет личной информации
- Покажите основные функции приложения
- Используйте светлую тему для лучшей читаемости

## Как сделать скриншоты

1. Запустите TTIsland
2. Используйте встроенную функцию "Снимок экрана" или Win+Shift+S
3. Сохраните файлы в эту папку
4. Обновите README.md, если нужно добавить больше примеров
